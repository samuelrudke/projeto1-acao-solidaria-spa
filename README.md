# 🚀 Projeto ONG Ação Solidária (SPA)

Aplicação Single Page Application (SPA) desenvolvida para a **ONG Ação Solidária**, focada em organizar recursos e facilitar a gestão e engajamento das causas da organização.

---

## 📌 Visão Geral e Apresentação do Projeto

O objetivo principal desta SPA é disponibilizar uma interface dinâmica, acessível e intuitiva para os utilizadores da ONG Ação Solidária. O projeto foi construído separando as responsabilidades de estrutura, estilo e comportamento, garantindo um código limpo e de fácil manutenção.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica de todas as páginas da SPA.
- **CSS3:** Estilização responsiva e moderna, adaptada para dispositivos móveis e desktop.
- **JavaScript (ES6+):** Lógica dinâmica da interface e validações de formulários no lado do cliente.
